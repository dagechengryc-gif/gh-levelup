# Profile README 模板

仓库名必须与你的 login **完全一致**（含大小写），且仓库公开。
新建后 GitHub 会自动在主页顶部渲染它的 `README.md`。

## 最小可用版（5 分钟）

```markdown
### Hi, I'm <NAME>

<一句话：我是谁 + 我在做什么 + 我能帮你什么>

- 🔭 正在做：<项目>
- 🌱 正在学：<技术>
- 💬 可以问我：<话题>
- 📫 找我：<邮箱 / X / 博客>
```

## 三条硬规则

1. **第一屏只放三样**：你是谁、你在做什么、别人怎么找你。技能条和访客计数器往后放。
2. **每个项目一句话说清"替谁解决什么"**，不要只写技术栈。
3. **链接必须活着**。指向已归档的仓库或 404 的博客，比不写更扣分。
